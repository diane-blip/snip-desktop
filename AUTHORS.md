# Authorship and dependencies

Snip was created by Diane Whiddon. This public edition continues her Windows capture tool with a separate release history, neutral interface, installation scripts, tests and documentation.

The app uses [Python](https://www.python.org/), [Tk](https://www.tcl.tk/), [MSS](https://github.com/BoboTiG/python-mss), [NumPy](https://numpy.org/), [Pillow](https://python-pillow.github.io/), [pystray](https://github.com/moses-palmer/pystray), [pywin32](https://github.com/mhammond/pywin32), [comtypes](https://github.com/enthought/comtypes) and [Playwright](https://github.com/microsoft/playwright-python). Installation downloads Chromium through Playwright. Those projects retain their own copyrights and licenses; Snip's MIT license covers Snip's source, not those dependencies.

The source archive does not bundle third-party packages, browser binaries or fonts. The interface uses Windows' installed Segoe UI. The camera icon is drawn by Snip's own icon function. Documentation examples and screenshots use fictional content.
